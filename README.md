# 记忆手帐 Memo Journal

> 一个带 AI 助理的个人便签手帐应用。支持选择 Claude Code、Codex 或 CodeBuddy CLI 作为 AI 后端，帮你整理碎碎念、追踪习惯、生成日周摘要、绘制任务关联图谱。

[![在线 Demo](https://img.shields.io/badge/🌐_在线_Demo-点击预览-E8B84B?style=for-the-badge&labelColor=4A3A28)](https://anselkocen.github.io/pls_collect_my_task/)
[![GitHub Release](https://img.shields.io/badge/📦_下载_Mac_App-Releases-4A3A28?style=for-the-badge&labelColor=E8B84B)](https://github.com/AnselKocen/pls_collect_my_task/releases)

> 🌐 **[在线 Demo 预览 →](https://anselkocen.github.io/pls_collect_my_task/)** 不用装任何东西，在浏览器里先逛一圈看看长什么样。Demo 内所有 AI 按钮均为静态模拟，完整功能请走下方安装步骤。

## ✨ 它能帮你做什么

- **随手记录** —— 写下碎碎念、待办、灵感，打标签分类
- **本地查找** —— 精确文字匹配或模糊关键词组合，无需 AI
- **AI 整理思路** —— 让 AI 帮你整理标签、生成日/周摘要、绘制思绪关联图谱
- **习惯养成** —— 上传任何书籍 ZIP（饮食、运动、观鸟手册…），生成专属习惯卡池，每天抽一张习惯卡打卡，用可爱胶带贴满日历
- **任务盲盒** —— 任务太多，不知道从何开始？迷茫时随机抽一条待办，让 AI 帮你做决定
- **定时提醒** —— 设置未来时间点，到点系统通知
- **多款主题** —— 提供多种主题色系，支持自定义配色

## 🚀 使用方法

### 方法一：下载 Mac 桌面 App（目前仅支持 Mac 用户）

#### 1) 准备 AI 助手（可选）
打开手帐，在「设置 → AI 助手」右侧下拉框选择 `cc`、`codex` 或 `codebuddy`。

| 选项 | 安装与登录 |
| --- | --- |
| cc | 安装 Claude Code CLI，在终端运行 `claude` 完成登录 |
| codex | 安装 Codex CLI，在终端运行 `codex` 完成登录 |
| codebuddy | 按 [CodeBuddy CLI 安装说明](https://www.workbuddy.cn/docs/cli/quickstart)安装，在终端运行 `codebuddy` 完成登录 |

选择自动保存，重启后继续使用；正在生成内容时暂时不能切换，成功或失败后恢复。手动生成、定时摘要和书籍习惯卡池都使用所选助手。

执行期间显示当前步骤和等待时长。点击任务气泡里的「查看过程」、生成按钮旁的「查看任务详情」或设置中的同名入口，可展开实时回答弹窗。关闭再打开会保留已有输出；刷新页面会重连并恢复当前任务输出。页面每两秒核对一次完整任务快照，打开弹窗和切回页面时也会立即核对；流式连接中断或漏收时会自动补齐回答和完成状态，旧事件不会覆盖新结果。Codex 整理调用使用单次 `medium` 推理强度，模型沿用用户的 Codex 配置；此参数只作用于手帐任务，不写入全局配置。Codex 通过 App Server 的文本增量事件接入。默认 OpenAI 配置下，手帐任务先只读检查有效配置和托管约束，再为单次进程选择 HTTP/SSE 传输，避开当前环境中默认连接反复超时的等待；模型和登录沿用 Codex 配置，不写入全局设置。自定义提供商、自定义 OpenAI 端点及被托管固定的提供商保持原配置。CC 和 CodeBuddy 使用 stream-json 部分消息。只展示公开回答，不展示内部推理或工具载荷。完整结果通过校验后才保存，失败时保留预览并显示提示。网络重试和长内容仍可能增加等待时间。实时预览仅在本次服务进程内保留最近一次任务，最多 32 段、512K 字符；正式摘要和图谱仍按原规则保存。

App 自动查找对应 CLI；找不到时，点击 AI 生成按钮可选择该助手的可执行文件。已有 `claude-config.json` 路径配置仍可使用。登录完成后直接重试，无需重启。没有 CLI 也能启动并使用便签、搜索、抽卡和提醒等基础功能。

#### 2) app下载
👉 **[前往 Releases 下载最新版](https://github.com/AnselKocen/pls_collect_my_task/releases)**

#### 3) 安装
1. 下载最新版的 `.dmg` 文件
2. 双击 dmg，会弹出一个窗口，里面有「记忆手帐」图标和「应用程序」文件夹的快捷方式
3. 把「记忆手帐」图标**拖到**旁边的「应用程序」文件夹里
4. ⚠️ **首次打开会弹窗提示「未打开"记忆手帐"」，这是正常的！** 按以下步骤操作：
   1. 弹窗点**「完成」**（不要点"移到废纸篓"）
   2. 打开 **系统设置 → 隐私与安全性**
   3. 往下滚，找到 **「已阻止"记忆手帐"以保护 Mac」**，点旁边的 **「仍要打开」**
   4. 弹出确认窗口，再次点 **「仍要打开」**，输入密码确认
   5. 之后就能正常使用了，以后不会再拦截

#### 更新版本

重新从 Releases 下载最新 `.dmg`，删除旧的「记忆手帐」app，把新版拖入「应用程序」文件夹即可。数据存储在 `~/Library/Application Support/记忆手帐/data/`，不会因为更新 app 而丢失。如果有重要数据，建议更新前先备份 `data/` 文件夹。

#### 4) 让定时提醒的系统通知长期显示
app 的定时提醒功能依赖 macOS 系统通知。默认情况下，macOS 通知会在几秒后自动消失，很容易错过。建议把它改成「横幅」模式，让通知**一直挂在屏幕右上角直到你手动关闭**：
1. 打开 **系统设置 → 通知**
2. 在应用列表里找到「**记忆手帐**」（首次用过一次通知后才会出现）
3. 点进去，把通知样式从「**临时**」改成「**横幅**」


> ⚠️ 目前app只提供 **Mac ARM64（Apple Silicon）** 版本。Intel Mac 和 Windows 用户请走方式二。

### 方式二：Git Clone 运行源码（Mac / Windows / Linux 都支持）

#### 1) 准备环境

a. **Node.js v22.16+**（仅源码运行版需要；桌面安装包自带运行环境）

检查是否已装，终端/命令行运行：
```bash
node -v
```

有版本号输出（比如 `v20.11.0`）即可。没装的话：
- **Mac**：`brew install node` 或从 https://nodejs.org 下载 LTS 版
- **Windows**：从 https://nodejs.org 下载 LTS 版，或 `winget install OpenJS.NodeJS.LTS`
- **Linux**：`sudo apt install nodejs npm` 或对应发行版的包管理器

b. **AI 助手 CLI**（可选，AI 生成功能需要）

安装并登录 Claude Code、Codex、CodeBuddy 中的任意一种，然后在手帐设置中选择。
源码运行版会从 PATH 和常见安装目录查找 CLI。使用自定义路径时，可在启动前设置对应环境变量：`CLAUDE_CLI`、`CODEX_CLI`、`CODEBUDDY_CLI`。这些变量只指定可执行文件路径，不保存登录凭证。

#### 2) 克隆项目

a. 先在终端/命令行 `cd` 到你想放项目的位置（桌面、某个工作目录、任意盘符都行）。

b. 克隆项目：

```bash
git clone https://github.com/AnselKocen/pls_collect_my_task.git
cd pls_collect_my_task
```

> 克隆会自动创建 `pls_collect_my_task/` 文件夹，所有代码都在里面。

#### 更新版本

在项目目录下执行 `git pull && npm install` 即可。`data/` 文件夹不受 git 管理，更新不会覆盖你的数据。

> ⚠️ 请勿删除整个项目文件夹重新 clone，否则 `data/` 目录会一并丢失。如需备份，先拷贝 `data/` 文件夹。

#### 3) 启动

a. **Mac / Linux：**
```bash
chmod +x start.sh stop.sh
./start.sh       # 启动
./stop.sh        # 停止
```

b. **Windows：**

最简单：在文件资源管理器里**双击 `start.bat`**。
或者在命令行运行：

```cmd
start.bat        REM 启动
stop.bat         REM 停止
```
> ⚠️ 如果你用的是 **PowerShell**（Windows 11 默认终端），需要在前面加 `.\`，例如 `.\start.bat` 和 `.\stop.bat`。

启动后浏览器会自动打开 http://localhost:3013

#### 日常使用（启动 / 停止）
a. **Mac / Linux：**
```bash
cd ~/Desktop/pls_collect_my_task   # 进入你当初克隆的项目目录
./start.sh                         # 启动
```
b. **Windows：**

直接**双击** `start.bat`，或者：
```powershell
cd C:\你\项目的\路径\pls_collect_my_task
.\start.bat
```

> 启动后浏览器会自动打开 http://localhost:3013。如果没自动打开，手动在浏览器里输入这个地址即可。

#### 关于终端窗口和停止服务

启动脚本会把服务放到后台运行，**可以关闭启动时的终端窗口**，服务会继续运行。
想停止服务时，即使之前启动的终端已经关了也没关系，**打开一个新的终端/命令行**，重新进入项目目录运行停止命令即可：

**Mac / Linux：**

```bash
cd ~/Desktop/pls_collect_my_task   # 进入项目目录（替换成你实际的路径）
./stop.sh
```

**Windows：**

```cmd
REM 进入项目目录（替换成你实际的路径）
cd %USERPROFILE%\Desktop\pls_collect_my_task
stop.bat
```

如果 `stop.sh` / `stop.bat` 不起作用，可以直接按端口杀进程作为兜底：
```bash
# Mac / Linux
lsof -ti :3013 | xargs kill
```

```cmd
:: Windows
for /f "tokens=5" %a in ('netstat -ano ^| findstr ":3013 " ^| findstr "LISTENING"') do taskkill /PID %a /F
```

> ⚠️ Windows 小注意：直接点窗口右上角 × 关闭命令行有小概率连带停止后台服务，推荐用 `stop.bat` 正常停止。

## 📚 功能介绍

### 📝 便签管理
- 快速记录、编辑、删除、置顶
- 自定义标签 + emoji + 胶带样式
- 标签筛选、关键词搜索
- 看板视图按标签分组展示

### 🤖 智能助手（需安装并登录所选 CLI）
- **本地查找** —— 默认精确匹配连续文字，忽略大小写和全角差异；模糊匹配支持忽略标点空格和关键词无序组合。搜索内容与标签，不做语义联想，也不调用 AI
- **整理标签** —— AI 分析便签，建议合并或新增标签
- **思绪图谱** —— 按内容分簇，保留网状关联、简短概括和原文来源；默认展开，可一键折叠为主题簇。支持标签和本地记录日期范围筛选
- **今日摘要** —— 每天 23:55 自动汇总电脑本地昨天和今天的手帐，按天分别概述（也可手动触发）
- **本周总结** —— 每周日 23:59 默认自动总结本地自然周（周一至周日、截至生成时刻），也可手动生成；日期、周编号和标签计数由程序确定

图谱、标签整理和日周摘要覆盖选定范围的全部便签，不再只取前 100 或每标签前 20 条。长内容和大量便签会分批分析后合并；整项任务期间占用同一个 AI 任务锁，防止其他生成或恢复穿插。界面显示分析条数，图谱的便签来源和关系引用会经过校验，失败的结果不会作为空图保存。范围过大、无法在合并预算内完成时会明确报错，请缩小标签或日期范围后重试。

提示词集中在 `tasks/prompts.js`，保留原有的内容关联、标签讨论和跨标签发散任务，仅适配数据库查询结果、记录时间和原文来源。图谱节点可自由提炼概念，不要求一条便签对应一个节点；分析条数表示送入分析的便签数。手动和定时任务共用 `tasks/service.js`；日摘要保留昨天和今天两段，周总结覆盖本地自然周。本地日期按运行应用的电脑时区计算，并使用日历边界处理夏令时。数据库升级会自动建立毫秒时间索引，原始便签时间字段保持原样；旧版数据库备份仍可恢复。

旧图谱和旧摘要的原内容保留，并标识缺失的来源或旧日期口径；重新生成后才会使用完整覆盖和本地日期的新规则。

### 🌻 特色玩法
- **习惯养成** —— 上传书籍 ZIP（饮食、运动、观鸟手册等），AI 从书里生成习惯卡池，每天抽一张打卡，填满打卡日历
- **任务盲盒** —— 选几个标签，随机抽一条待办，让 AI 帮你做决定
- **定时提醒** —— 设置未来日期+时间，到点系统通知

### 🎨 主题配色
- 多款预设主题
- 自定义配色
- 每个标签可单独设置 emoji 和胶带样式

## ❓ 常见问题

### Q：点 AI 生成按钮后没有结果

先查看「设置 → AI 助手」选中了哪一种，再在终端运行对应命令 `claude`、`codex` 或 `codebuddy`，确认已经完成登录且有可用额度。随后回到手帐重试。

提示未安装时，请确认该 CLI 在 PATH 中，或为源码版设置对应路径环境变量；桌面版也可在配置弹窗中选择可执行文件。提示登录失败时，请重新登录所选助手。界面使用所选产品名称提示安装和登录问题，其他任务提示不绑定某一家助手。

### Q：今日摘要/本周总结没有自动生成

**自动生成需要 app 在对应时间点处于运行状态。**

- 今日摘要：每天 23:55 触发（可在设置里改）
- 本周总结：每周日 23:59 触发

如果那一刻 app 没开，就会错过那次自动触发。你可以随时手动点「重新生成」补上。

### Q：AI 操作要多久才出结果？

取决于所选助手、模型响应速度和便签数量。期间会显示正在处理的任务。

**一次只运行一个 AI 任务**。任务运行期间不能切换助手；其他 AI 请求会提示“正在处理上一项任务，请稍等～”。

### Q：升级新版 app 后，之前的数据还在吗？

**在。** 数据目录：

- **Mac 桌面 App**：`~/Library/Application Support/记忆手帐/data/`，覆盖安装不会动这个目录
- **Mac / Linux 源码运行版**：项目根目录下的 `data/` 文件夹
- **Windows 源码运行版**：项目根目录下的 `data\` 文件夹

业务数据保存在这个目录中的 **`memo.sqlite`**，使用 Node/Electron 内置的 SQLite，用户无需安装数据库。

### Q：旧版 JSON 数据怎么迁移？

新版首次启动会自动读取原来的 6 个业务 JSON 文件，先备份到 `data/backups/legacy-时间-编号/`，再通过事务导入并逐项核对。便签 ID、时间、顺序、标签配置、AI 历史、卡池、打卡和提醒都会保留。缺失文件会使用对应的空数据或默认设置，不会向已有用户插入欢迎便签或默认卡池。

原始 JSON 不会被覆盖。迁移成功后，新修改只写入 SQLite；重启不会重复导入 JSON。若文件损坏、记录 ID 重复或迁移校验失败，服务会停止并说明原因，数据库不会保留一半的导入结果。请先关闭旧版本再启动新版。

### Q：如何备份、恢复或迁回旧版？

打开 **设置 → 数据与备份**：

- **立即备份**：生成一致的 SQLite 快照，可以下载保存。
- **导出 JSON**：下载含 6 个兼容旧版 JSON 文件的 ZIP。要迁回旧版，先关闭应用，将这些文件解压到旧版的数据目录。迁移前留下的旧 JSON 不会包含新版中新增的记录。
- **恢复**：选择列表中的备份，或上传 `.sqlite` / `.db` 文件（最大 100 MB）。程序先验证文件与版本、备份当前数据，再在事务中恢复；失败会回滚。恢复期间暂停写入，AI 正在运行时不能恢复。成功后页面自动刷新。

每次启动时，如果本地当天还没有自动备份，会自动创建一份，保留最近 7 份。手动备份、恢复前备份和旧 JSON 迁移备份不会被自动清理。请将重要备份另存到其他位置；同一个硬盘上的备份不能防止硬盘损坏。

请优先使用应用内的备份入口。需要手动复制整个数据目录时，应先关闭应用。未来版本的数据结构可能不同，旧版应用不会强行打开版本更高的数据库。SQLite 数据库本身没有启用内容加密。

### Q：我想改每日摘要的时间

每日摘要默认在 23:55、本周总结默认在周日 23:59 生成。设置接口 `/api/settings` 支持更新 `dailyDigestTime`、`weeklyDigestDay` 和 `weeklyDigestTime`，时间格式为 `HH:mm`。迁移后请勿通过修改旧 `settings.json` 配置应用，它不再是当前数据源。

### 开发验证

```bash
npm test
```

测试使用系统临时目录，覆盖旧数据迁移、失败回滚、关联写入、逐记录更新、备份恢复、提醒和 HTTP 接口；不会迁移项目现有 `data/`。还覆盖空内容、空图拒绝保存、模型返回异常、任务锁释放、本地习惯日期及面向用户的提示文案。AI 接口测试使用模拟 CLI，覆盖三种助手流式分发、SSE 断线重连、预览保留、运行中拒绝切换、定时任务、习惯卡池、失败解锁和设置持久化，不能替代真实模型的内容质量验收。接口测试需要允许监听本机临时端口。Node 22.16 的 `node:sqlite` 可能输出实验性接口提示，这不是数据库初始化失败。

### Q：不想用 AI 功能也能用吗？

可以。没有安装 AI 助手 CLI 的话，便签管理、标签筛选、搜索、看板、主题切换、定时提醒这些功能都能正常用，只是智能助手和习惯养成的部分功能会不可用。
