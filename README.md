> 一个带 AI 助理的个人便签手帐应用。支持选择 Claude Code、Codex 或 CodeBuddy CLI 作为 AI 后端，帮你整理碎碎念、追踪习惯、生成日周摘要、绘制任务关联图谱。

## ✨ 它能帮你做什么

- **随手记录** —— 写下碎碎念、待办、灵感，打标签分类
- **本地查找** —— 精确文字匹配或模糊关键词组合，无需 AI
- **AI 整理思路** —— 让 AI 帮你整理标签、生成日/周摘要、绘制思绪关联图谱
- **习惯养成** —— 上传 TXT、ZIP、Word（DOC/DOCX）、PDF 或粘贴文字，也可以和 AI 助手聊聊近期计划，生成专属习惯卡池，每天抽一张习惯卡打卡，用可爱胶带贴满日历
- **任务盲盒** —— 任务太多，不知道从何开始？迷茫时随机抽一条待办，让 AI 帮你做决定
- **定时提醒** —— 设置未来时间点，到点系统通知
- **多款主题** —— 提供多种主题色系，支持自定义配色

## 🚀 使用方法

### 方法一：下载 Mac 桌面 App（目前仅支持 Mac 用户）

#### 1) 准备 AI 助手（可选）
打开手帐，点击「设置」展开 AI 助手切换，再从文字下拉框选择 Claude Code、Codex 或 CodeBuddy。其他设置默认保持显示。

| 选项 | 安装与登录 |
| --- | --- |
| cc | 安装 Claude Code CLI，在终端运行 `claude` 完成登录 |
| codex | 安装 Codex CLI，在终端运行 `codex` 完成登录 |
| codebuddy | 按 [CodeBuddy CLI 安装说明](https://www.codebuddy.cn/docs/cli/quickstart)安装，在终端运行 `codebuddy` 完成登录 |

Trae 的选择和运行入口已暂时关闭，底层适配代码保留。国内 Trae CLI 2.0 仅向企业旗舰版套餐客户开放，当前个人账号没有 CLI 使用权限；见[官方使用限制](https://docs.trae.cn/cli_about-trae-code-cli-2)和[企业套餐对照](https://docs.trae.cn/trae-enterprise_billing-overview-for-trae-enterprise?lang=zh)。关闭前的 19 个源文件与测试另存为 [Trae 适配备份](backups/trae-cli-adapter-2026-11-23.zip)，不含凭证或日记数据。

旧设置若选中了 Trae，运行时优先回退到已安装的 Codex，其次 CodeBuddy，最后 Claude Code；原本选择这三种助手的设置保持不变。

选择自动保存，重启后继续使用；正在生成内容时暂时不能切换，成功或失败后恢复。手动生成、定时摘要和书籍习惯卡池都使用所选助手。

执行期间只显示当前步骤和等待时长，不显示「前往查看」。本周总结、标签建议、图谱、卡池及计划问答完成后，才显示对应入口并定位本次结果；每日摘要和查找便签的结果就在首页，不提供跳转按钮。定位只展开并滚动到结果，不添加整块高亮或程序焦点框。任务进行中仍可关闭页面内的弹窗继续做别的事，后台生成不受影响。统一的原始回答过程弹窗已移除；计划对话继续流式显示问题和选项。页面每两秒核对任务快照，切回页面时立即同步；流式连接中断、漏收或旧事件不会覆盖更新的状态。

Codex 整理调用使用单次 `medium` 推理强度，模型沿用用户的 Codex 配置；此参数只作用于手帐任务，不写入全局配置。Codex 通过 App Server 的文本增量事件接入。默认 OpenAI 配置下，手帐任务先只读检查有效配置和托管约束，再为单次进程选择 HTTP/SSE 传输，避开当前环境中默认连接反复超时的等待；模型和登录沿用 Codex 配置，不写入全局设置。自定义提供商、自定义 OpenAI 端点及被托管固定的提供商保持原配置。CC 和 CodeBuddy 使用 stream-json 部分消息；保留的 Trae 底层适配使用 ACP 回答增量事件，当前没有开放入口。后台仅记录助手实际返回的公开回答，不记录私有推理或工具载荷。完整结果通过校验后才保存，失败时保留已收到的回答及错误，便于排查。网络重试和长内容仍可能增加等待时间。最近一次 AI 任务记录保存在数据目录的 `latest-ai-task.json`，下一次任务覆盖，回答最多32段、512K字符，超限会标记截断；服务重启后仍可读取，未正常结束的旧任务会标记为中断。正式摘要、图谱和卡池按原规则保存，不受这份诊断记录覆盖影响。

App 自动查找对应 CLI；找不到时，点击 AI 生成按钮可选择该助手的可执行文件。已有 `claude-config.json` 路径配置仍可使用。登录完成后直接重试，无需重启。没有 CLI 也能启动并使用便签、搜索、抽卡和提醒等基础功能。

首次打开和每次本地服务重新启动，都只自动显示欢迎与 AI 助手检测弹窗；关闭后，同一服务运行期间刷新页面不会重复弹出。标题左侧使用项目 favicon 猫头，右侧「查看详细指南」可打开独立的项目与功能介绍（含版本和 GitHub 源码链接），关闭指南后返回欢迎页并保留检测结果。底部主题色横条左侧的白色圆圈像素问号可随时重开欢迎页，带轻微浮动，减少动态效果设置下保持静止。Mac 版与连接本机服务的网页版使用相同流程。

启动检测只执行 CLI 版本、帮助和受支持的认证状态命令，不发送模型提示词。检测结果区分未安装、明确未登录、已检测到登录状态、登录状态未确认；无法确认不会被当成不可用，也不会自动切换当前助手。状态检查不能保证账号额度、模型权限与网络一定正常。CodeBuddy 暂时只检查 CLI，认证状态显示未确认。

只有手动点击「测试连接」才发送固定简短消息，可能消耗少量模型额度；不附带便签，在独立临时目录执行，并禁用工具及自定义 MCP 等扩展。缺少安全测试能力的旧 CLI 会提示升级，不降级为不受限调用。测试与整理共用任务锁，结果不会覆盖摘要、图谱或任务历史。明确未安装或未登录的助手不显示测试按钮；配置完成后可「重新检测」。关闭弹窗即可先使用基础记录功能。

连接测试仅供参考，不影响直接使用 AI 功能。Claude Code / CodeBuddy 的受限测试不加载用户或项目的自定义设置；只在这些设置中提供的自定义服务或认证助手可能无法参与测试，CLI 自身保存的登录和进程环境认证仍会沿用。

引导与检测的界面回归可运行 `node test/onboarding-ui.js`（用 `MEMO_PLAYWRIGHT` 和 `MEMO_CHROME` 指定 Playwright / Chrome）。该检查只使用内存接口和合成记录，覆盖双弹窗顺序、服务重启、显式测试、失败重试、基础记录及窄屏布局，不调用真实 CLI 或模型。


#### 关于终端窗口和停止服务

启动脚本会把服务放到后台运行，**可以关闭启动时的终端窗口**，服务会继续运行。
想停止服务时，即使之前启动的终端已经关了也没关系，**打开一个新的终端/命令行**，重新进入项目目录运行停止命令即可：

**Mac / Linux：**

```bash
cd ~/Desktop/pls_collect_my_task   # 进入项目目录（替换成你实际的路径）
./stop.sh
```

**Windows：**

```cmd
REM 进入项目目录（替换成你实际的路径）
cd %USERPROFILE%\Desktop\pls_collect_my_task
stop.bat
```

如果 `stop.sh` / `stop.bat` 不起作用，可以直接按端口杀进程作为兜底：
```bash
# Mac / Linux
lsof -ti :3013 | xargs kill
```

```cmd
:: Windows
for /f "tokens=5" %a in ('netstat -ano ^| findstr ":3013 " ^| findstr "LISTENING"') do taskkill /PID %a /F
```

> ⚠️ Windows 小注意：直接点窗口右上角 × 关闭命令行有小概率连带停止后台服务，推荐用 `stop.bat` 正常停止。

## 📚 功能介绍

### 📝 便签管理
- 快速记录、编辑、删除、置顶
- 自定义标签 + emoji + 胶带样式
- 标签筛选、关键词搜索
- 看板视图按标签分组展示

### 🤖 智能助手（需安装并登录所选 CLI）
- **本地查找** —— 默认精确匹配连续文字，忽略大小写和全角差异；模糊匹配支持忽略标点空格和关键词无序组合。搜索内容与标签，不做语义联想，也不调用 AI
- **整理标签** —— AI 分析便签，建议合并或新增标签
- **思绪图谱** —— 按内容分簇，保留网状关联、简短概括和原文来源；默认展开，可一键折叠为主题簇。支持标签和本地记录日期范围筛选
- **今日摘要** —— 每天 23:55 自动汇总电脑本地昨天和今天的手帐，按天分别概述（也可手动触发）
- **本周总结** —— 每周日 23:59 默认自动总结本地自然周（周一至周日、截至生成时刻），也可手动生成；日期、周编号和标签计数由程序确定

图谱、标签整理和日周摘要覆盖选定范围的全部便签，不再只取前 100 或每标签前 20 条。长内容和大量便签会分批分析后合并；整项任务期间占用同一个 AI 任务锁，防止其他生成或恢复穿插。界面显示分析条数，图谱的便签来源和关系引用会经过校验，失败的结果不会作为空图保存。范围过大、无法在合并预算内完成时会明确报错，请缩小标签或日期范围后重试。

提示词集中在 `tasks/prompts.js`，保留原有的内容关联、标签讨论和跨标签发散任务，仅适配数据库查询结果、记录时间和原文来源。图谱节点可自由提炼概念，不要求一条便签对应一个节点；分析条数表示送入分析的便签数。手动和定时任务共用 `tasks/service.js`；日摘要保留昨天和今天两段，周总结覆盖本地自然周。本地日期按运行应用的电脑时区计算，并使用日历边界处理夏令时。数据库升级会自动建立毫秒时间索引，原始便签时间字段保持原样；旧版数据库备份仍可恢复。

旧图谱和旧摘要的原内容保留，并标识缺失的来源或旧日期口径；重新生成后才会使用完整覆盖和本地日期的新规则。

### 🌻 特色玩法
- **习惯养成** —— 在“卡池”页拖拽或上传 TXT、ZIP、Word（DOC/DOCX）、文字型 PDF，或直接在同一素材框内粘贴文字，再点击“生成专属习惯卡池”，生成30张素材专属习惯卡。选文件或拖入文件后会先显示文件名，确认生成前可更换、移除或切换回文字，两类草稿互相保留。文件最大20MB，文字最多20万字符；长文件取前20万字符并提示，扫描 PDF 需先识别文字。也可点击“和AI助手聊聊近期计划”，在独立小弹窗里选择目的和投入方式；两轮问题流式显示，每轮提供三个 AI 选项及“其他，我来补充”。开始生成后自动收起对话，在卡池页显示进度；重新打开保留回答，失败可重试。成功打开本次卡池后收起完成提示，对话记录继续保留。每天抽一张卡打卡，填满打卡日历
- **任务盲盒** —— 选几个标签，随机抽一条待办，让 AI 帮你做决定
- **定时提醒** —— 设置未来日期+时间，到点系统通知

## ❓ 常见问题

### Q：点 AI 生成按钮后没有结果

先查看「设置 → AI 助手」选中了哪一种，再在终端运行对应命令 `claude`、`codex` 或 `codebuddy`，确认已经完成登录且有可用额度。随后回到手帐重试。

提示未安装时，请确认该 CLI 在 PATH 中，或为源码版设置对应路径环境变量；桌面版也可在配置弹窗中选择可执行文件。提示登录失败时，可重新登录所选助手。界面使用所选产品名称提示安装和登录问题，其他任务提示不绑定某一家助手。

### Q：今日摘要/本周总结没有自动生成

**自动生成需要 app 在对应时间点处于运行状态。**

- 今日摘要：每天 23:55 触发（可在设置里改）
- 本周总结：每周日 23:59 触发

如果那一刻 app 没开，就会错过那次自动触发。你可以随时手动点「重新生成」补上。

### Q：AI 操作要多久才出结果？

取决于所选助手、模型响应速度和便签数量。期间会显示正在处理的任务。

**一次只运行一个 AI 任务**。任务运行期间不能切换助手；其他 AI 请求会提示“正在处理上一项任务，请稍等～”。

### Q：升级新版 app 后，之前的数据还在吗？

**在。** 数据目录：

- **Mac 桌面 App**：`~/Library/Application Support/记忆手帐/data/`，覆盖安装不会动这个目录
- **Mac / Linux 源码运行版**：项目根目录下的 `data/` 文件夹
- **Windows 源码运行版**：项目根目录下的 `data\` 文件夹

业务数据保存在这个目录中的 **`memo.sqlite`**，使用 Node/Electron 内置的 SQLite，用户无需安装数据库。

### Q：旧版 JSON 数据怎么迁移？

新版首次启动会自动读取原来的 6 个业务 JSON 文件，先备份到 `data/backups/legacy-时间-编号/`，再通过事务导入并逐项核对。便签 ID、时间、顺序、标签配置、AI 历史、卡池、打卡和提醒都会保留。缺失文件会使用对应的空数据或默认设置，不会向已有用户插入欢迎便签或默认卡池。

原始 JSON 不会被覆盖。迁移成功后，新修改只写入 SQLite；重启不会重复导入 JSON。若文件损坏、记录 ID 重复或迁移校验失败，服务会停止并说明原因，数据库不会保留一半的导入结果。请先关闭旧版本再启动新版。

### Q：如何备份、恢复或迁回旧版？

打开 **设置 → 数据与备份**：

- **立即备份**：生成一致的 SQLite 快照，可以下载保存。
- **导出 JSON**：下载含 6 个兼容旧版 JSON 文件的 ZIP。要迁回旧版，先关闭应用，将这些文件解压到旧版的数据目录。迁移前留下的旧 JSON 不会包含新版中新增的记录。
- **恢复**：选择列表中的备份，或上传 `.sqlite` / `.db` 文件（最大 100 MB）。程序先验证文件与版本、备份当前数据，再在事务中恢复；失败会回滚。恢复期间暂停写入，AI 正在运行时不能恢复。成功后页面自动刷新。

每次启动时，如果本地当天还没有自动备份，会自动创建一份，保留最近 7 份。手动备份、恢复前备份和旧 JSON 迁移备份不会被自动清理。请将重要备份另存到其他位置；同一个硬盘上的备份不能防止硬盘损坏。

请优先使用应用内的备份入口。需要手动复制整个数据目录时，应先关闭应用。未来版本的数据结构可能不同，旧版应用不会强行打开版本更高的数据库。SQLite 数据库本身没有启用内容加密。

### Q：我想改每日摘要的时间

每日摘要默认在 23:55、本周总结默认在周日 23:59 生成。设置接口 `/api/settings` 支持更新 `dailyDigestTime`、`weeklyDigestDay` 和 `weeklyDigestTime`，时间格式为 `HH:mm`。迁移后请勿通过修改旧 `settings.json` 配置应用，它不再是当前数据源。

测试使用系统临时目录，覆盖旧数据迁移、失败回滚、关联写入、逐记录更新、备份恢复、提醒和 HTTP 接口；不会迁移项目现有 `data/`。还覆盖空内容、空图拒绝保存、模型返回异常、任务锁释放、本地习惯日期及面向用户的提示文案。底层仍保留四种 CLI 适配器及协议测试；当前应用接口和 UI 只开放 `cc`、`codex`、`codebuddy`。AI 接口测试使用模拟 CLI，覆盖流式分发、SSE 断线重连、预览保留、运行中拒绝切换、定时任务、习惯卡池、失败解锁和设置持久化，不能替代真实模型的内容质量验收。接口测试需要允许监听本机临时端口。Node 22.16 的 `node:sqlite` 可能输出实验性接口提示，这不是数据库初始化失败。

愿望卡池的提示词及校验位于 `tasks/habit-wish.js`。接口测试还覆盖两轮引导、流式问题、回答传递、重复内容拒绝保存，以及连接中断后的幂等重试。桌面交互冒烟测试可运行 `./node_modules/.bin/electron test/habit-wish-ui-smoke.js`；如 Electron 内置 Node 不满足项目版本要求，用 `MEMO_TEST_NODE` 指定 Node 22.16+ 可执行文件。设置 `MEMO_UI_SCREENSHOT_DIR` 可保存桌面与窄屏截图。该测试使用隔离临时数据，验证四个选项、自由补充、对话收起与恢复、失败重试及卡池详情。

像素猫的动画、状态控制和实时任务同步检查也包含在 `npm test` 中。主界面联调可运行 `./node_modules/.bin/electron test/cc-cat-ui-smoke.js`，同样可用 `MEMO_TEST_NODE` 指定 Node 22.16+。该测试使用隔离数据库和模拟 CLI，验证思考、工作、查找、整理、成功、失败、连续任务、历史记录恢复、闲逛、窄屏气泡布局及减少动态效果设置，不调用真实 AI。报告和截图默认保存在系统临时目录，可用 `MEMO_CAT_UI_REPORT` 和 `MEMO_CAT_UI_SCREENSHOT` 指定路径。

主页面的空闲计时只累计没有播放动作的时间：首次等待5秒，之后每站等待22秒、每段走路8秒，轻动作每3秒、休闲动作每10秒触发。动作播放时等待、走路和动作间隔均暂停，完成后从原进度继续；行走中也可停下来做动作，因此实际往返时间会超过180秒。任务开始会立即取消空闲动作并接管；页面隐藏则冻结进度、丢弃当前空闲动作，返回后继续。新增动作与行走暂停的界面专项为 `node test/cc-cat-leisure-ui.js`，可用 `MEMO_PLAYWRIGHT`、`MEMO_CHROME` 指定运行依赖，用 `MEMO_CAT_LEISURE_EVIDENCE` 指定报告目录；该专项只使用合成数据。

小猫说话使用独立于动作的统一30秒节拍：第30、60秒邀请「喵嗷，去不去咪的家里玩？」，停留10秒，无关闭按钮，点击「前往」在新页面打开线上猫咪小屋并携带当前显示的主题；邀请显示期间换主题，链接立即同步，点击时也会重新读取。自定义主题通过URL片段携带六个配色值，跨站打开仍保持小猫和界面配色，小屋背景沿用最接近的预设场景。第90秒随机显示原有碎碎念，停留2.5秒，此后按同样顺序循环。任务气泡出现立即停止说话计时，完成或失败提示保留到关闭；点击提示的 × 后从第一个30秒重新计时。页面隐藏或小猫临时互动时跳过当次说话机会，不补发。对话专项为 `node test/cc-cat-dialogue-ui.js`，使用模拟数据和浏览器虚拟时钟，可通过 `MEMO_PLAYWRIGHT`、`MEMO_CHROME` 指定运行依赖。

小屋「猫咪的秘密基地」使用随主题切换的像素控件，副标题为「一屋子的喜欢，咪都给你。」。进入后自动闲逛，到达每个位置停留10秒再换下一处；位置下拉框只显示名称，配合左右箭头可随时选点，手动选点后照常继续闲逛。点击小猫只会随机播放思考、小困惑或开心挥爪，动作结束后继续原活动；点击互动和页面隐藏期间会暂停原活动与停留倒计时。底部仅居中显示闲逛状态，不显示动作说明；全页背景有随主题变色的缓慢漂浮像素爪印与小光点，不拦截操作，隐藏页面时暂停，减少动态效果时隐藏。小屋保留缩放、拖动、主题切换与保存图片，移除探索、清单、提示词、昼夜和暂停入口；系统的减少动态效果设置仍生效。小屋专项为 `node test/cat-sanctuary-ui.js`，使用模拟数据和浏览器虚拟时钟，可通过 `MEMO_PLAYWRIGHT`、`MEMO_CHROME` 指定运行依赖。

独立静态发布可运行 `node scripts/build-cat-sanctuary.js`（或 `npm run build:cat-sanctuary`），输出到 `output/cat-sanctuary-site/`。发布包仅包含小屋、24个主题和主页面同款猫头 favicon，不包含手帐后端、用户数据或部署密钥；`manifest.json` 记录每个文件的 SHA-256。独立版通过 `data-room-settings="local"` 在浏览器保存主题，不访问手帐 API；原手帐内的小屋仍沿用已有设置同步。可通过 `?theme=mintchoc` 等参数直达对应主题，并支持子路径托管。静态包专项为 `node test/cat-sanctuary-static-ui.js`。服务器、发布路径、项目密钥位置和回退信息记录在已排除 Git 与发布包的 `.deploy/cat-sanctuary.json` 中，后续同项目更新复用有效授权和专用密钥。
