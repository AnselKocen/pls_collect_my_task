# 前端体验优化实施计划（2026-11-25）

## 已确认范围

1. 猫咪：去掉偶发外框；适当放大；脚底贴齐活动区域下边框；提高左右移动的可见频率。
2. 设置：使用胶带、纸张底色减少大块纯白；Agent 名称首字母大写并增加像素风图标；直接删除“查看任务详情”按钮。
3. 查找：标题改为“查找便签”；输入框和匹配方式选择器等高对齐；删除精确和模糊匹配解释文字。
4. 习惯素材：入口改为“拖拽or上传素材，生成素材专属习惯卡池！”；删除 pdf2app 引导段落；支持 TXT、ZIP、Word、PDF、粘贴文字。
5. 习惯对话：使用 💬 和“和AI助手聊聊近期计划，为你生成专属习惯卡池！”；点击打开独立二层小弹窗；开始生成卡池时自动收起二层窗，主卡池显示生成中。
6. 图谱：取消包住节点和标签的粗蓝框，采用节点本身及其关联关系的自然高亮。

## 实施顺序与分工

### A. 猫咪显示和活动
- 检查全局 focus 样式和猫咪容器，区分鼠标点击与键盘导航，保留适当键盘反馈。
- 在猫咪专用样式中统一正常/翻转尺寸，校准像素素材的脚底位置与移动边界。
- 调整空闲停顿和移动触发，让左右走动更常见；任务进行时保持现有任务状态优先级。
- 验收：点击不出现矩形框；桌面和窄屏都不悬空、不越界；观察到左右移动且状态切换不被打断。

### B. 设置、查找与图谱
- 使用现有主题变量制作纸张与胶带底色；增加代码原生像素 Agent 图标，名称统一大小写。
- 删除设置区任务详情按钮及其专属绑定，保留运行中其他任务入口。
- 调整查找布局与文案，清理匹配解释的更新逻辑，保留搜索结果状态与错误反馈。
- 选中图谱节点时使用局部光晕、描边和文字强调，移除包围整个 SVG 节点组的默认矩形 outline。
- 验收：各主题可读；查找字段对齐；搜索模式仍正常；图谱点击、悬停及键盘选择可用。

### C. 习惯对话交互
- 将对话内容放入独立二层模态层，提供关闭/收起入口和合理焦点管理。
- 保留问答、流式输出、自定义回答、重试以及重新打开后的对话状态。
- 真正进入卡池生成阶段时自动收起对话；主卡池呈现生成中，可重新查看；完成或失败有明确反馈。
- 父弹窗关闭时同步处理子弹窗显示，生成任务不中断。
- 验收：不在第一轮提问时提前收起；最终生成自动收起；重新打开不丢答案；失败可重试；窄屏可滚动操作。

### D. 多格式素材生成
- 复用现有生成与保存链路，增加统一素材解析模块及清晰的输入校验。
- TXT 提取文本；ZIP 保留原有 skills.zip/文本目录兼容性；Word 解析正文；PDF 提取文字；粘贴文字直接作为素材。
- 前端同时支持选择文件、拖拽和文字提交，生成状态和错误反馈统一。
- 限制文件与提取文本大小，清理临时上传；损坏文件、空文本、无文字 PDF 等明确报错，不产生空卡池。
- 验收：每种输入实际通过 API 进入生成并保存 30 条习惯；文件名正确；原 ZIP 回归；失败不保存；可重试。
